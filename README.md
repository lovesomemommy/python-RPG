# Львёнок

**Что делает программа:** консольный виртуальный питомец. Пользователь заводит львёнка, даёт ему имя и заботится о нём: кормит, играет с ним и укладывает спать. У львёнка есть три показателя от 0 до 100: сытость, настроение и энергия. После каждого действия он немного голодает и скучает. Если сытость упадёт до нуля, львёнок убежит и игра закончится.

## Требования

Python 3. Сторонние библиотеки не нужны.

## Как запустить

```
python main.py
```

Автоматические проверки:

```
python tests.py
```

## Устройство

Львёнок хранится в словаре: имя и три показателя. Каждое действие вынесено в свою функцию: `feed`, `play` и `sleep` меняют показатели и возвращают сообщение для пользователя. `limit` следит, чтобы показатели не выходили за 0 и 100. `time_passes` уменьшает сытость и настроение после каждого хода, а `get_state` по показателям возвращает, какой сейчас львёнок: голодный, сонный, грустный или довольный.

## Проверки

**Проверка 1 (обычный сценарий).** Вход: львёнок с показателями 50/50/50, его кормят, потом с ним играют. Ожидание: сытость 80, настроение 75, энергия 30, после хода сытость 70, состояние «довольный». Результат: совпадает.

**Проверка 2 (необычный сценарий).** Вход: попытка поиграть с уставшим львёнком (энергия 10), кормление сытого львёнка (сытость 90), неизвестная команда в меню, пустое имя. Ожидание: уставший львёнок отказывается играть и показатели не меняются, сытость не поднимается выше 100, на неизвестную команду программа отвечает «Такой команды нет.», при пустом имени львёнка зовут «Лео». Результат: совпадает.

Основные проверки также записаны в `tests.py` через `assert`.
